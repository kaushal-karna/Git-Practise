03 — Learn by doing

Practice on real repositories

Reading about git rebase doesn't teach you git rebase. This does.

Clone the repository

Pull the course repo down to your machine and open it in your editor.

git clone https://github.com/kaushalkarn/git-learn.git

Open the lesson folder

Each lesson has its own folder with a task file and a starter repo.

cd lessons/06-merging

Complete the exercise

Follow the prompt inside TASK.md and run the commands yourself.

git status

Compare your solution

Check your work against SOLUTION.md and see where you diverged.

git diff solution

Master it

Repeat with the next lesson until the commands feel like muscle memory.
